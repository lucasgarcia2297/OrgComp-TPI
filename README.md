### Modules
**PC.v** -> Contador de Programa.<br>
**IM.v** -> Memoria de Instrucciones.<br>
**BR.v** -> Banco de Registros.<br>
**DM.v** -> Memoria de Datos.<br>
**SE.v** -> Extensión de Signo.<br>
**ALU.v** -> Unidad Aritmético Lógica.<br>
**Adder.v** -> Sumador.<br>
**Mux2x1.v** -> Multiplexor 2x1.<br>
